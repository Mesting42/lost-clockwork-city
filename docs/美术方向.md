# 失落机关城 · 美术方向

用户选择：精致童话机械遗迹。视觉的中心是一座可触摸的立体机械模型，而非满屏面板。

- 水息工坊：岸石 #80918a、深水 #285c60、铜 #b87547、黄铜 #e0b46d、微光 #b7f2ce。
- 镜光庭院：青石 #688b97、夜蓝 #1c384b、银 #b9d4d6、琥珀光 #ffe1a2、三角青蓝光 #7de4ec。
- 星陨核心：玄武岩 #454663、暗紫 #1e223b、紫铜 #a794c1、星光 #d5b8f7、旧金 #d0ad78。
- 标题使用本地衬线字体栈：华文中宋、宋体、serif。正文使用微软雅黑、苹方、sans-serif。资源没有远程字体请求。
- 主菜单左侧留出安静的标题与开始入口，右侧展示完整的水力工坊立体场景。游戏中上缘是目标，下缘是操作；机关说明仅在选择后展开。
- 记忆点：模型底座下垂的铜管、流动水轮与一颗小小的探险者，让整个关卡像一座重新活起来的机械音乐盒。

自检：去除装饰仪表、营销卡片和大面积霓虹。所有线条用于展示机关身份、轨道、压力状态或光路。
