# 失落机关城 · 测试与交付记录

验证日期：2026 年 10 月 9 日（Asia/Shanghai）。测试机器为本项目所在 Windows 电脑。所有浏览器通关均从空白浏览器上下文的新游戏开始，使用正常键盘、鼠标及游戏按钮输入。

## 生产构建

`npm run build` 已成功。应用与 Three.js 分开打包，游戏逻辑约 84 kB、Three.js 约 486 kB（未压缩）；没有需要远程访问的资源。`dist/` 包括可直接由本地服务提供的生产文件、原创模型与许可清单。

## 逻辑验证

`npm test` 共 34 项通过：

- 18 关各自从初始状态到出口的完整合法回放。
- 每关加入合法绕行后，仍能完成；通关条件不依赖固定操作顺序。
- 无效移动不修改原状态或消耗操作。
- 人物 / 箱体压力板身份、离开恢复、闸口占用安全。
- 水位真实影响通行、浮箱成为通路、禁止隔空操作、禁止在无支撑渠床上升水。
- 光束受箱体遮挡、镜面反射、正确能源身份、反射循环上限。
- 重力按轨道确定停靠，在木箱前停止，不穿透物体。
- 全部关卡的完整状态快照撤销、恢复与重新分支。
- 点击寻路不会自动推箱或穿越锁门。
- 新增设置兼容性、范围校验、导出校验，以及四段交替脚步、支撑脚锚定、膝关节 IK 和脚底水平测试。

合法序列保存在 `tests/solutions.json`，最短验证序列为每关 6～25 个有效步骤，共 235 个步骤。最短序列用于回归，不能作为真人首玩用时估计。

## 浏览器完整主线

`npm run test:browser` 在安装的 Chrome 中执行。测试只读查看状态，操作通过 `keyboard.press`、鼠标选择场景机关与界面按钮完成。

已经走通新游戏 → 6 个水力关卡 → 6 个镜光关卡 → 6 个重力 / 综合关卡 → 城市核心重启 → 真实记录结算 → 回访重玩。全关卡 `won` 与 `ready` 均由机关状态正常得出，没有设置胜利标志、直接开门、改箱体坐标或跳关。

专项检查包括：

- 暂停后方向输入不修改状态，手动保存、刷新与继续恢复状态及撤销历史。
- 第 6 关结算页面刷新后，继续游戏恢复该结算与进入下一章的入口。
- 三层提示按主动展开次数计数。
- 结局正常播放后进入结算；此前独立完整回归也验证了“跳过演出”路径。
- 重玩保留已解锁章节与 18 关记录，不产生重复解锁。
- 重置只恢复当前关卡，并计入重试。
- 低画质与静音设置可用。
- 1440×960 桌面、390×844 手机竖屏、844×390 手机横屏、1024×1366 平板模拟视口。
- 手机方向按钮可移动；横竖屏变化保留关卡与撤销历史。
- 手机和平板竖屏会阻塞游戏并显示横屏按钮；横屏后解除阻塞，浏览器能力不足时显示手动旋转说明。
- 快速连续方向键会即时重定向正在播放的步行动画，每个按键保持一次逻辑操作。
- 没有未捕获浏览器异常，没有外部运行资源请求。

详细逐关结果：`artifacts/browser-report.json`。设置、横屏和行走专项结果见 `artifacts/enhancements-report.json`。该报告会由最近一次完整回归更新，不手工修改结果。

## 异常操作与触控

`node tests/resilience.mjs` 已通过 9 项专项检查：

1. 动画期间撤销原子取消移动并恢复状态。
2. 快速重复按键不会跳过逻辑边界。
3. 动画期间重置消除待完成运动并恢复初始机关。
4. 切换另一个浏览器标签再返回，保持一致的逻辑状态。
5. 故意破坏存档版本 / 校验外层后，显示恢复页并恢复有效备份。
6. 新游戏确认可以取消，不删除进度。
7. 手机游戏界面所有可见按钮实际触控区域至少 44×44 CSS 像素。
8. 用 Chrome DevTools 协议模拟双指缩放，人物与机关状态不受影响。
9. 横竖屏切换保存完整关卡与历史。

报告：`artifacts/resilience-report.json`。存档破坏发生在应用启动之前，仅测试恢复流程，不改变解锁或关卡状态。

## 启动器与端口

Windows PowerShell 5.1 实跑已修复 UTF-8 脚本 BOM 与中文 HTTP JSON 解码兼容性。启动器已实际通过 HTTP 身份检查、复用已有服务、打开浏览器与打印局域网地址。

`node tests/server.mjs` 验证占用 5190 端口时自动改用 5191，原测试服务保持运行；同时检查健康身份、HTML 文件类型、缺失资源返回 404，以及路径越界返回 403。端口检查包含回环 TCP 预探测，覆盖 Windows 上回环地址与通配地址可能同时绑定的问题。测试只关闭它自己创建的服务，恢复原游戏运行记录。

报告：`artifacts/server-report.json`。

## 验证边界

- 手机和平板为 Chrome 模拟视口、触控事件及双指手势，**没有进行实体手机 / 平板真机测试**。
- 未进行 Safari、Firefox、iOS 音频策略和不同移动 GPU 的实机兼容性测试。
- 音频通过 Web Audio 生成，并在用户手势后启动；没有对实际扬声器输出做录音或听感验收。
- 已在电脑上验证局域网监听与地址输出，未用实体手机连接验证不同路由器 / 防火墙环境。
- 提示词的 30～50 分钟为首玩体验目标，尚未进行真人首次探索计时；自动化知道解法，不能证明该时长。
