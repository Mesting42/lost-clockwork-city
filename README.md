# 失落机关城

一款原创、非像素风的浏览器 3D 空间机关解谜游戏。你扮演带着微光的机械探险者，在水息工坊、镜光庭院与星陨核心中修复十八处机关，唤醒城市。

项目目录：`D:\AnLi\失落机关城`。所有游戏代码、模型、材质、界面、音乐与资源均在本地提供。没有素材 CDN、远程字体、在线 AI 或付费接口。

## 启动

Windows 双击 `启动游戏.bat`。启动器会检查 Node.js 和依赖，必要时安装依赖并构建；后台启动本游戏服务，通过 HTTP 健康检查后打开浏览器，并显示电脑和当前局域网地址。再次运行会复用同目录的本游戏服务。占用端口属于其他服务时，自动寻找空闲端口，不会结束其他项目。

需要 Node.js **22.12 或更新版本**，以及支持 WebGL 的现代 Chrome、Edge、Firefox 或 Safari。当前开发和回归使用 Node.js 22.18、安装在电脑上的 Chrome。仅实际验证了 Chrome，其他浏览器需要各自验证。

默认电脑入口：<http://localhost:5180>。若该端口占用，以启动器输出为准。

手机与平板：连接相同局域网，输入启动器显示的 `http://电脑局域网IP:端口`。IP 每次启动重新检测，记录于 `.runtime.json`。程序不修改防火墙，不提供公网部署。

手机和平板用竖屏打开时会显示“请横屏游玩”并暂停游戏。点击“横屏游玩”会尝试全屏和屏幕方向锁定；浏览器不支持时会给出手动旋转提示，实际转为横屏后自动继续。桌面窗口保持自由方向。

已提供 `dist/` 生产构建。游戏运行不需要访问网络上的资源；首次缺少开发依赖时，`npm ci` 需要联网。

终端启动与开发：

```powershell
cd D:\AnLi\失落机关城
npm ci
npm run dev
```

生产服务：

```powershell
npm run build
node tools/serve.mjs
```

## 完整流程

主菜单 → 新游戏 / 继续 → 章节入场 → 每区 6 关 → 区域核心修复 → 第 18 关水力、重力、光束综合解谜 → 城市亮灯演出 → 胜利结算 → 自由回访。

| 区域 | 关卡 | 机制 |
| --- | --- | --- |
| 水息工坊 | 第一声回响、绕过旧齿轮、两座沉默的闸门、浮起的桥、给水流一块踏脚石、工坊重新呼吸 | 推箱、持续压力板、联动门、水位、浮台、提前放置浮箱 |
| 镜光庭院 | 一束迟到的光、回廊里的折线、挪开阴影、彼此照亮、闸门背后的星光、庭院的两次日出 | 离散镜面、三次反射、遮挡、菱形琥珀与三角青蓝能源、遮光闸、推箱组合 |
| 星陨核心 | 重新认识方向、拐角的落点、恰好的阻挡、被星光托起的水、星轨与光轨、让城市重新呼吸 | 定向重力、折角轨道、木箱止挡、水力与重力、光路与重力、三机制综合 |

每关根据实际机关状态判断出口是否可用，不要求固定操作顺序。全部关卡都有经逻辑求解和浏览器实际输入回放验证的合法序列，详见 `tests/solutions.json`。这些文件用于开发回归，不在正式游戏界面展示。

设计体验目标为慢节奏的首次探索，不按速度评分，不用计时等待延长过程。提示词中的 **30～50 分钟**目标尚未经过真人首玩计时验证；浏览器回归预先知道解法，不能代表玩家的探索时长。

## 操作

| 操作 | 桌面 | 手机 / 平板 |
| --- | --- | --- |
| 移动 / 推箱 | 方向键或 WASD | 左下方向键 |
| 自动步行 | 点击可达空地，不自动推箱 | 点选可达空地 |
| 选择机关 | 点击场景物件 | 点选场景物件 |
| 阀门 / 镜面 | 站到相邻格按 E，或选中后点击操作按钮 | 站到相邻格，点选后使用操作按钮 |
| 改变重力 | 选中罗盘，点击四方向按钮 | 同左 |
| 撤销 / 重置 | Z / R，或底部按钮 | 底部按钮；重置需确认 |
| 暂停 | Esc 或右上按钮 | 右上按钮 |
| 镜头 | 拖动平移、滚轮缩放、右下旋转与还原 | 拖动平移、双指缩放、右侧旋转与还原 |

方向键始终对应地图网格方向；镜头旋转不会改变网格规则。旋转手机不会重开关卡或清空撤销历史。双指缩放与单指点击分别识别，面板不会把触控穿透到场景。

方向键采用即时响应：上一步的视觉行走还没有结束时，新的方向会从当前画面位置重新衔接，快速连续按键不会被吞掉。每个按键仍经过一次完整的逻辑碰撞判定，因此不会因为连按穿墙、重复推箱或跳过机关。

设置面板分为声音、画面、操作、存档四组：音乐和音效独立音量、试听与静音；精致 / 均衡 / 轻盈画质、亮度和减少动态效果；方向键大小与左右布局、镜头灵敏度、点击行走；以及立即保存、导出、导入和恢复偏好。恢复偏好不会删除关卡进度，导入存档会先校验并要求确认。

## 机关规则与防卡关

- 机关箱由玩家推移，不会自由滚动。压力板需要持续压住，木箱可以遮挡光束。门口有人或箱体时，安全棘爪保持门开启，离开后重新判断。
- 低水位允许走渠床、推动浮箱。高水位让浮台升到步道高度，并使水中浮箱成为踏脚石；其他深水位置不可走。先在干岸准备浮箱，再升水。
- 光束采用与画面完全相同的网格射线。遇墙、箱体、关闭的闸门或固定装置停止，镜面按“／”和“＼”反射；接收器仅接受同符号能源。存在反射循环检测和步长上限，能源门从无电状态求稳定结果，不能循环自供电。
- 星陨箱只在可见轨道内移动。选择方向后持续受到该方向重力，停在轨道末端或第一个障碍物之前。玩家站位和普通箱体都能成为止挡；规则不依赖帧率。
- 有效移动、推动与机关操作保存完整逻辑快照。无效动作不消耗操作或历史。撤销恢复人物、箱体、镜面、水位、重力、门和光路；撤销时、重置时可以原子取消动画。暂停冻结过渡；后台不补算移动。
- 保留最近 160 次撤销，存档保留最近 80 次。撤销后重新操作会形成新分支。重置仅影响当前关卡，可从任何死局恢复。

## 提示与评分

每关有三个主动展开的提示层级：观察重点、关键规则、下一步建议。第一次展开每一层增加一次提示计数，重复打开同一层不重复扣分。提示不阻断出口。

三颗星：没有使用提示，也没有重置；两颗星：提示不超过 2 次且重置不超过 1 次；其余合法完成获得一颗星。有效操作统计包含成功移动、推动、交互与有效撤销，重置单独计数。没有速度要求。

重玩不会重复解锁；最佳记录先比较星数，再比较操作数，再比较提示与重试次数。胜利结算展示已完成关卡的真实最佳记录之和。结束后可回访全部章节。

## 存档

本地存档命名空间为 `lost-clockwork-city:*`，不覆盖其他游戏。每次逻辑步骤自动保存，也可在暂停菜单手动保存。

存档包括当前关卡、完整机关状态、有限撤销历史、统计、章节解锁、最佳成绩和设置。保存发生在已提交的原子逻辑边界；即使画面正在过渡，恢复时也会准确放置对象。

主存档 `lost-clockwork-city:save:v1` 使用版本号、FNV-1a 校验以及机关结构检查。上一份有效存档保存在 `lost-clockwork-city:backup:v1`。损坏或不兼容时显示恢复界面，可恢复备份，或保留原始数据到恢复槽再重开。新游戏清空进度需要明确确认，画面与音量设置保留。

**存档按浏览器与访问来源隔离**。`localhost`、`127.0.0.1`、局域网 IP、不同端口，以及手机和电脑的存档互不共享。建议电脑固定使用启动器打开的 `localhost` 地址。清除浏览器站点数据会删除对应存档。

## 声音、画质与资源

三章分别使用原创本地合成音乐，机关音效覆盖脚步、推箱、阀门、镜面、开门、水位、接通能源、重力、提示、撤销、错误与完成。第一次点击或键盘操作后解锁音频，音乐与音效独立调节，支持静音。没有远程音频或音频接口。

高画质提供阴影、浮尘和最多 2 倍像素比；均衡限制为 1.4；低画质关闭阴影与浮尘，限制为 1。所有档位还有总像素预算，均保留光路、轨道与压力状态。静态建筑按材质合并绘制，切关释放旧几何体、材质与光束对象；全局输入只注册一次。

原创程序化资源与可复用探险者 / 箱体模型位于 `src/scene.js` 和 `public/models/`。导出的模型是原生 Three.js JSON，可由 `THREE.ObjectLoader` 解析。素材清单与来源许可在 `public/ASSET-SOURCES.md`，第三方通用库完整许可位于 `public/licenses/`。代码与原创模型采用项目 MIT 许可。

## 测试与开发结构

```powershell
npm test                         # 逻辑回放与机关边界
node tools/verify-levels.mjs      # 重新求解并保存十八关合法操作序列
npm run build                    # 生产构建
node tools/serve.mjs              # 运行生产服务后，在另一终端执行以下测试
npm run test:browser              # 新游戏正常输入完成十八关、结局、重玩与响应布局
node tests/resilience.mjs         # 动画中撤销/重置、存档恢复、触控与旋转
node tests/server.mjs             # 端口避让、HTTP 身份与静态服务边界
node tools/export-models.mjs      # 导出并重新解析本地模型
```

浏览器测试默认使用本机 `C:\Program Files\Google\Chrome\Application\chrome.exe`。可用 `CHROME_PATH` 指定浏览器，用 `CITY_URL` 指定服务入口。

`src/engine.js` 为不依赖渲染的确定性逻辑；`src/locomotion.js` 为交替步伐、脚底锚定和双节腿 IK；`src/levels.js` 为十八关原创布局与提示；`src/scene.js` 为模型、灯光、镜头、动画和拾取；`src/main.js` 为界面、输入、流程与存档；`src/audio.js` 为原创合成音乐与音效；`src/storage.js` 为存档版本与校验。

测试报告和截图保存于 `artifacts/`。详细验证范围和未验证项见 `docs/测试报告.md`。回归仅只读查看游戏状态，通关通过真实键盘、鼠标和界面按钮完成；不修改关卡编号、箱体位置、解锁进度或胜利标记。存档恢复专项测试会故意损坏存档外层，以验证恢复页面，不借此跳关。
